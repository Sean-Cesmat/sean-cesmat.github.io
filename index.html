This internal project modernized Indigo Slate’s brand and web presence. I led development using a headless CMS approach, enabling cross-departmental updates with ease. We used Storyblok as the CMS and built the frontend with Nuxt.js and Vue, configured for SSR to meet CSP requirements.

I translated Figma designs into reusable components, wired them to dynamic inputs in Storyblok, and handled rendering logic. The final result was a performant, modular site with GSAP and Lottie animations to enhance storytelling and UI/UX.

Collaborators: Copywriters, designers, video editors, marketers, and a PM.

Triview is a cloud-based analytics platform built on Microsoft Azure, providing real-time portfolio insights for commercial real estate investors and servicers. I collaborated closely with another front-end developer and a cross-functional team to deliver interactive dashboards, advanced filtering, and data visualization tools. My focus was on building modular, reusable Vue components and ensuring a seamless, responsive user experience across all devices. The platform features export/download capabilities and was engineered for both performance and accessibility.

Key Contributions: Component architecture, D3 data visualizations, export features, and responsive design.

Azure Global Infrastructure is an interactive 3D globe experience for Microsoft, allowing users to explore the company’s worldwide datacenter network. I worked alongside a 3D designer, copywriters, and technical strategists to develop globe interaction logic, integrate live data, and animate network lines. The project demanded high performance, accessibility, and precise mapping of global locations. Built with Vue/Nuxt, GSAP, and Babylon.js, this immersive experience highlights Microsoft’s infrastructure and sustainability initiatives.

Key Contributions: 3D globe logic, data integration, performance optimization, and accessibility.
